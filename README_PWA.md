# 社工考试题库 PWA 使用说明

## 什么是 PWA？

PWA（Progressive Web App）是一种渐进式网页应用，可以像原生 App 一样安装到手机主屏幕上，支持离线使用，无需从应用商店下载。

---

## iPhone 使用方法

### 添加到主屏幕

1. 使用 **Safari 浏览器** 打开社工考试题库网页
2. 点击屏幕底部的 **分享按钮**（方框向上箭头的图标）
3. 在弹出的菜单中，向下滑动找到 **"添加到主屏幕"**
4. 点击 **"添加"**
5. 返回主屏幕，即可看到"社工题库"图标

### 使用提示

- 必须使用 **Safari** 浏览器，Chrome 或其他浏览器不支持此功能
- 添加后，从主屏幕点击图标即可打开，体验与原生 App 一致
- 首次打开需要联网加载，之后支持离线使用

---

## Android 使用方法

### 添加到主屏幕

1. 使用 **Chrome 浏览器** 打开社工考试题库网页
2. 点击浏览器右上角的 **菜单按钮**（三个点）
3. 选择 **"添加到主屏幕"** 或 **"安装应用"**
4. 确认安装
5. 返回主屏幕，即可看到"社工题库"图标

### 使用提示

- 推荐使用 **Chrome** 浏览器
- 部分 Android 手机会自动弹出"安装应用"提示条，直接点击即可
- 首次打开需要联网加载，之后支持离线使用

---

## 离线使用说明

本应用采用 **Service Worker** 缓存技术，所有题目数据均已嵌入 HTML 文件中：

- **首次访问**：需要联网，浏览器会自动缓存所有资源
- **后续访问**：即使没有网络连接，也可以正常使用全部功能
- **缓存更新**：如果网页内容有更新，在有网络连接时访问会自动更新缓存

### 清除缓存

如果遇到显示异常，可以清除浏览器缓存后重新访问：
- **iPhone**：设置 > Safari > 清除历史记录与网站数据
- **Android**：Chrome 设置 > 隐私和安全 > 清除浏览数据

## 功能特点

- **720道精选题目**：覆盖4本社工考试教材
- **四大模块**：社会工作综合能力、社会工作实务、社会工作法规与政策、社会工作综合能力（中级）
- **章节练习**：按章节分类，逐章攻克
- **模拟考试**：随机抽题，模拟真实考试环境
- **错题收藏**：自动记录错题，方便复习巩固
- **答题统计**：实时显示正确率和答题进度
- **离线可用**：无需网络，随时随地刷题
- **原生体验**：全屏模式，无浏览器地址栏干扰
